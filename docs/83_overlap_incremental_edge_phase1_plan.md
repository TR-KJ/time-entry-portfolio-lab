## State reconstruction, frozen before outcomes
For each portfolio separately, sort by EntryTime and process all exactly simultaneous entries as one batch. An open other trade satisfies strictly `other_entry < candidate_entry < other_close`, using actual CloseTime, never ScheduledExitTime. Same-time entries cannot open state for each other. State precedence for unique primary label:
1. Entry timestamp shared by at least two portfolio trades, regardless of symbol: `SIMULTANEOUS_BATCH`.
2. Any same-symbol other trade has CloseTime exactly at candidate EntryTime, or strict open same-symbol positions include BOTH directions: `BOUNDARY_AMBIGUOUS` (record reason `EXIT_EQUALS_ENTRY` or `MIXED_DIRECTIONS`).
3. Strict open same-symbol position of candidate direction: `SAME_SYMBOL_SAME_DIR_OPEN`.
4. Strict open same-symbol position of opposite direction: `SAME_SYMBOL_OPPOSITE_DIR_OPEN`.
5. Otherwise: `NO_SAME_SYMBOL_OPEN`.
The label is exhaustive and unique; store detailed boolean/count fields and boundary reason locally. Simultaneous batches retain strict prior open positions in diagnostics but never enter formal same/no comparison. Entry==exit of the candidate itself is invalid; baseline ordering and unique trade identities are audited.

Cross-symbol currency exposure uses strict open positions in DIFFERENT symbols at entry, independent of same-symbol label. Compare signs for each shared currency between candidate and all open positions. If both aligned and opposed shared-currency matches occur, `MIXED_CROSS_SYMBOL_EXPOSURE`; aligned only => `CROSS_SYMBOL_ALIGNED_EXPOSURE`; opposed only => `CROSS_SYMBOL_OPPOSED_EXPOSURE`; none => `NO_SHARED_CURRENCY_EXPOSURE`. Purely diagnostic; no Phase 1 rule. A2b requires a separate Plan.

## Bootstrap and inference
For each primary strategy independently, cluster by Monday-start JST calendar week of EntryTime. Period assignment precedes clustering; boundary weeks include only their respective period's trades. Include occupied weeks of the strategy, not empty calendar weeks. In chronological key order, use NumPy PCG64 Generator seed 20260913; reinitialize for every strategy. For each of 5,000 replicates, sample the original number of occupied Recent Combined weeks with replacement, retaining all trades and multiplicities and jointly reconstructing same/no state means from the fixed ORIGINAL state labels. Do not recompute state after sampling; this is a diagnostic bootstrap, not portfolio replay. Report unadjusted percentile 2.5/97.5 linear-interpolation CIs for overlap AvgR, no-overlap AvgR and their difference. A replicate with zero required-state trades invalidates inference for that strategy without redraw/drop. One-sided negative-tail approximate bootstrap p for the difference is `(1 + count(bootstrap OVERLAP_DIFF >= 0))/(5001)`. This p is descriptive bootstrap tail evidence, not random-assignment causal inference.

Formal Holm family: all 27 primary-strategy differences as one family, including insufficient/undefined strategies assigned p=1. Stable tie order strategy number; Holm step-down adjusted p. Criterion E is adjusted p <0.05, not CI exclusion. Historical/Recent A/B/Monitor comparisons and 28-strategy robustness have no new formal candidate tests. Strategy-specific Recent Combined sufficient floor: overlap >=30 trades and >=20 occupied weeks; no-overlap >=30 trades and >=20 occupied weeks; valid bootstrap. For descriptive period CIs outside Recent Combined, report no inference if a state is empty.

For global primary27 diagnostic, independently cluster occupied whole-portfolio Recent Combined weeks with the same seed/5,000 draws and fixed states. Report overlap/no-overlap pooled means, TotalR, counts, CI and pooled difference. Independently calculate equal-weight within-strategy difference and cluster-bootstrap CI by drawing portfolio weeks jointly for all strategies; require at least five strategies with both states meeting the individual sample floor. The global suppression rule advances only if overlap AvgR<0, its unadjusted 95% CI upper<0, equal-weight adjusted difference<0 and its unadjusted 95% CI upper<0, and both global states have >=30 trades/>=20 weeks. ## Formal individual candidate gate
For each primary27 strategy, `OVERLAP_SUPPRESSION_CANDIDATE` iff ALL:
A Recent Combined overlap AvgR<0.
B Its valid 95% CI upper<0.
C Same-strategy Recent Combined no-overlap AvgR>=0.
D OVERLAP_DIFF<0.
E Holm-adjusted one-sided p<0.05.
F Both states meet sample floor and bootstrap valid.
G Recent A AND Recent B overlap AvgR<0, each with >=15 trades and >=10 occupied weeks. Monitor is displayed but not a gate because partial 2026 may be sparse.
Strict inequalities fail on equality, except C's >=. If G fails, do not rescue via Monitor. `INSUFFICIENT_SAMPLE` if F fails; `OVERLAP_STILL_POSITIVE` if F passes and overlap AvgR>0; `WEAK_OVERLAP_SIGNAL` if A,C,D pass but B/E/G fails; otherwise `NOT_SUPPORTED`. Show A–G PASS/FAIL for all strategies. A negative within-strategy difference with positive overlap AvgR never qualifies.
