# B6 SL価格較正・集計前規約（新提案、未採用）

2026-09-27。実データの価格統計を初めて実行する前に保存する規約。
探索損益は使わない。対象はnaive JSTで2020-01-01 <= t < 2024-01-01。
入力全期間のhash/行数/端点/重複/OHLC監査と、この価格統計への配列引渡しを分離する。

主物差しはJST火〜金の「十分なデータがある暦日」の日次High−Low (pips) の中央値D。
月曜の市場開始前・土曜早朝の短縮日を主較正から外すため火〜金とする。
12/25〜1/3を価格統計から除く。その他の休日は名称で除かず同じデータ充足条件で除く。
各日>=1380個の一意なM1、最初の足<=00:05、最後>=23:55、連続する足の最大間隔<=10分。
欠損は補間しない。条件から除外された日数・理由を報告。最低合計600日かつ各年100日、未達ならSL数値は保留。
この価格統計の日条件を戦略の取引除外に流用しない。

SLはD × [0.15, 0.30, 0.50, 0.80, 1.20]、5pipsへのhalf-up丸め。
下限10pips、上限300pips。順に前値+5以上へ補正、上限を超えるなら5値すべて保留。
clamp/重複補正の有無を出力し、補正があれば探索開始前に再確認する。損益を見て作り直さない。
0.15〜1.20の8倍幅で短時間から日跨ぎまでを粗くカバーするための新提案であり、最適性は主張しない。
説明用の20/35/50/75/100%を合意済みと扱わない。

補助診断は同じ適格日のJST固定00:00起点30分・4時間ブロックのHigh−Low中央値。
全分が存在するブロックだけを使用。これをSL候補別・時間帯別較正に使わない。
日次の年別中央値・全期間Q25/Q75も出力するが、結果で倍率を調整しない。
