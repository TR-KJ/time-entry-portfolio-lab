## 再利用した計算仕様
初期資金500,000 JPY。Riskは0.25 / 1.0 / 1.5 / 2.0%、正式代表1.5%。0.25%は保守的live参照で研究代表とは別。旧v1.1と過去risk比較の50万円・1/1.5/2%を再利用した。
Weekly Fixed Riskは「週内の各取引のRiskAmount固定」、Weekly Compoundは「翌週に複利更新」で、同じ計算を表す。別の非複利モードは作成していない。
JST月曜06:00週、週初Balance×Risk、週内同額、翌週に確定PnL反映。2015年から継続し、IS/OOSで残高やDDピークをリセットしない。初期資金をピークに含めるDD初期化だけをv1.1から修正。入力に週跨ぎ未決済・報告期間跨ぎ取引はなく、未来の決済損益を週初Baseへ含めない前提検証を通過。
主modeはTHEORETICAL_UNCAPPED。PnL=RiskAmount×Pips/SL。SLは行ごとの値を使用。RawLot=RiskAmount/(SL×pip value)、Lot=RawLotでpip valueは約分。lot min/max/step/MaxAutoLot制約なし。固定Rとの最大差は4.7368421052631578947368421052632E-10RでCSVの丸め差。Phase 2の保存Rは変更なし。

## 採否と解釈
代表1.5%ではALL FinalCapital改善と継続OOS純利益改善を両方必須、他の3 Riskでも両差分>=0を必須と事前固定。すべて減少し不通過。DDやOOS Rの改善で救済しない。
22除外の既知OOS Delta +9.362857140Rに対し、IS Delta -39.377142872R・ALL -30.014285732R。ISで失った利益により、M1のOOS開始資金が小さくなる。OOS区間だけの成長率と、2015年から継続した最終資産/円純利益は異なる指標である。本研究は後者を正式優先し、同額OOS再スタートは実行していない。「同額からOOSのみ運用しても悪化する」とは主張しない。
OOS Worst Week Rは既知の0.301428571R悪化。今回代表1.5%のOOS WorstWeekはM0 -19.236602%、M1 -19.688745%と0.452143 percentage points悪化。OOS MaxDD%は改善するが、ALL MaxDD%は悪化した。
2022〜2026は既閲覧で完全未閲覧holdoutではない。2026は9/9までの部分年。将来の収益、実際に発注可能な金額、統計的有意性は主張しない。

## 実運用制約付きmodeの限界
状態はNOT_RUN_MISSING_HISTORICAL_BROKER_INPUTS。固定Baselineに過去JPY pip value、symbol volume min/max/step、週初浮動Equityがないため、実運用制約付き数値比較は実行していない。これは計画時点で固定した範囲である。
EAはJST月曜00:00週キー、週最初のBase要求時Equity/GV固定、MaxAutoLot=1.00、AllowMinLot=true。min/max clip→lot step切捨て→小数2桁のhelperを既存仕様から実装・人工入力でテストした。研究の06:00/Balance/無制約と混同しない。数値RawLotを架空の為替レートで埋めていない。検証を進める場合も、この理論研究の結果を上書きせず別研究とする。
