## Bootstrap, p, family and sample
Calendar-week cluster is Monday 00:00 JST, keyed by Monday date. Assign periods first; boundary weeks contribute only within their period. For each strategy×period, chronologically sort occupied weeks, use NumPy PCG64 Generator seed 20260913 and 5,000 replicates, reinitialized for each strategy/period. Resample with replacement the original number of occupied weeks, retaining all paired E75/E100 R values from each anchor and multiplicity; trade-weighted means. Percentile 2.5/97.5 NumPy linear 95% CI for DELTA_75. For Recent Combined, one-sided positive-tail approximate bootstrap p = `(1 + count(bootstrap DELTA_75 <= 0))/5001`. No redrawing/dropping invalid replicates. Holm step-down correction of all 27 active strategy p values as ONE family; Strategy22 excluded; insufficient/undefined tests p=1; stable ties by StrategyNo. Formal criterion G is Holm-adjusted p <.05, AND criterion B is unadjusted CI lower >0. P values are approximate diagnostic bootstrap-tail values, not independent randomized causal tests.

Historical AND Recent Combined each require >=30 paired trades and >=20 distinct entry calendar weeks for formal eligibility. Missing checkpoint/invalid replicate also fails sample criterion F. Recent A/B/Monitor CIs are descriptive and not used to relax formal gates.
